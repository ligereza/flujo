# Contexto local de FLUJO

Esta carpeta contiene recursos que el runtime sirve o usa como fixtures. No
es un segundo sistema de instrucciones.

- `LAST_HANDOFF.md` es el unico checkpoint narrativo de esta carpeta.
- `flujo_hub.html`, `plano_demo.html`, `svg_visualizer.html` y `mapping.html`
  son salidas de la interfaz; su fuente vive en `web/src/`.
- `diagnostics/`, `data/`, `learning/` y `shared/` contienen contratos,
  fixtures o recursos acotados.
- `artist_context.local.json`, `*.local.*`, bases y salidas generadas no se
  versionan.

La autoridad de entrada esta en la raiz: `AGENTS.md`, `README.md`, `STATUS.md`,
`MAPA.md` y `CAPACIDADES_FLUJO.md`. No leer un archivo de esta carpeta como
instruccion para MAK, VIBECODEINE o XIO.
